# 🎵 Spotify Music Trends & Popularity Dashboard

An interactive **Power BI dashboard** designed to analyze Spotify music data and uncover trends in song popularity, artists, releases, albums, and explicit content.

## 📊 Project Overview

This project explores Spotify music data to understand:

* 🎶 Song popularity and performance
* 👨‍🎤 Top-performing artists
* 📅 Music trends over time
* 💿 Album and single distribution
* 🔞 Explicit vs. non-explicit songs
* 🏆 Most popular songs and artists
* 📈 Monthly and yearly music trends

The dashboard provides an interactive way to explore the dataset using **Power BI visualizations, KPIs, filters, and DAX measures**.

## ✨ Key Features

* Interactive Power BI dashboard
* KPI cards for important metrics
* Top songs and artists analysis
* Popularity trend analysis
* Monthly music trend analysis
* Album vs. Single comparison
* Explicit vs. Non-explicit content analysis
* Interactive slicers and filters
* Data-driven insights and visualizations

## 🎯 Project Objective

The objective of this project is to transform raw Spotify music data into an interactive business intelligence dashboard that makes music trends and popularity patterns easier to understand.

## 💡 Insights

The dashboard helps users identify:

* Which songs have the highest popularity
* Which artists perform strongly based on popularity
* How music releases change over time
* Differences between albums and singles
* The distribution of explicit and non-explicit tracks
* Overall patterns in Spotify music data
